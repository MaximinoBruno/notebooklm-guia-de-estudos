# 📚 Treinando uma IA de Aprendizagem com o Gemini Notebook

## 📌 Sobre o projeto

Este projeto foi desenvolvido como parte do desafio da DIO com o objetivo de explorar o Gemini Notebook (antigo NotebookLM), uma ferramenta de Inteligência Artificial baseada nos modelos Gemini.

O foco foi aprender como utilizar documentos como fonte de conhecimento para criar resumos, responder perguntas, gerar glossários e organizar estudos.

---

## 🎯 Objetivos

- Conhecer o funcionamento do Gemini Notebook.
- Aprender a utilizar fontes de informação.
- Explorar técnicas de Engenharia de Prompts.
- Criar um guia de estudos utilizando IA.
- Organizar o conteúdo em um repositório no GitHub.

---

## 🛠️ Tecnologias utilizadas

- Gemini Notebook (NotebookLM)
- Inteligência Artificial
- GitHub
- Markdown

---

## 📂 Estrutura do projeto

- README.md
- guia-estudos.md
- glossario.md
- prompts.md
- referencias.md

---

## 📚 O que aprendi

Durante este desafio aprendi:

- Como utilizar o Gemini Notebook para estudar.
- Como criar prompts eficientes.
- Como gerar resumos e glossários com IA.
- A importância de utilizar fontes confiáveis para reduzir erros nas respostas.

---

## 🚀 Conclusão

O Gemini Notebook demonstrou ser uma ferramenta muito útil para organizar informações, revisar conteúdos e apoiar o processo de aprendizagem com Inteligência Artificial.
