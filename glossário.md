# Glossário

## Alucinação de IA
Resposta incorreta ou sem fundamento gerada por uma Inteligência Artificial.

## Machine Learning
Área da IA em que os algoritmos aprendem com dados para fazer previsões ou tomar decisões.

## Deep Learning
Subárea do Machine Learning que utiliza redes neurais profundas para resolver problemas complexos.

## IA Generativa
Tecnologia capaz de criar conteúdos inéditos, como textos, imagens, vídeos e áudios.

## LLM (Large Language Model)
Modelo de linguagem treinado com grandes volumes de texto, utilizado por ferramentas como ChatGPT e Gemini.

## Multimodal
Capacidade de uma IA compreender diferentes tipos de dados, como texto, imagem, áudio e vídeo.

## Rede Neural
Estrutura computacional inspirada no funcionamento do cérebro humano.

## Transformers
Arquitetura de redes neurais utilizada nos modelos modernos de IA generativa.
